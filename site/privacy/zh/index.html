隐私权
政策

生效及最后更新：2026 年 10 月 26 日

简要说明

仅在您主动使用账号功能时访问浏览器状态。敏感账号状态会在扩展内加密后再同步。我们不会出售数据，也不会将其用于广告。

适用范围

本政策适用于 Cookie Share Next 浏览器扩展及官方服务 https://cookie.nestlone.com。自托管部署由相应管理员运营，并可能适用附加政策。

完整政策

我们如何处理您的信息

01

产品用途

Cookie Share Next 用于在用户自己的浏览器之间保存和切换其有权使用的网站登录状态。只有当您主动要求保存或切换账号时，扩展才会读取登录状态。敏感浏览器状态会在扩展内加密后再同步；服务端只保存加密信封，无法解密其中内容。

02

扩展访问的数据

为完成您主动请求的功能，扩展可能访问：

  • 当前标签页的 URL、主机名、标题和图标，用于识别当前网站；
  • 当前网站的 Cookie，包括 Chromium 允许访问的 HTTPOnly Cookie 和分区 Cookie；
  • 当前网站同源的 localStorage 与 sessionStorage；
  • 扩展设置、服务器地址、扩展登录会话和本地加密状态；
  • 您明确选择导入或导出的账号备份文件。

扩展不会持续扫描标签页、收集浏览历史、注入广告，也不会使用这些数据建立用户画像。

03

官方服务接收的数据

  • OAuth 提供商、该提供商分配的账号标识符以及登录名或显示名称；使用 Google 登录时，可能包括 Google 返回的电子邮箱地址。
  • 加密账号桶、不透明桶标识符、密文大小以及时间戳。
  • 服务会话令牌和备用登录密钥的密码学哈希；备用密钥明文仅显示一次，服务端不保存明文。
  • 短期 OAuth 状态和交换记录。
  • 用于执行请求限制和保护服务的账号 ID、API 路径及时间戳。
  • 用于短期限流和防止滥用的请求 IP 地址。
  • Cloudflare 在交付和保护服务时处理的技术请求元数据。

OAuth 访问令牌仅临时用于获取最少量身份信息，Cookie Share Next 不会保存该访问令牌。

04

数据用途

我们仅将数据用于身份验证、按照用户请求关联登录提供商、同步加密账号桶、执行配额、防止滥用、维护安全、排查运行故障，以及提供用户请求的导入、导出、切换和删除功能。

我们不会出售个人数据。我们不会将用户数据用于或转移给个性化广告、重新定向广告、信贷决策或无关分析。服务端不持有保险库密码或解密密钥，因此人工无法读取已解密的 Cookie 或浏览器存储。

05

加密与安全

Cookie 值、已保存的浏览器存储、桶名称及相关账号状态内容会在上传前于扩展内加密。保险库密码及派生解密密钥保留在扩展内。官方服务仅接收这些内容的加密信封，网络通信使用 HTTPS。

任何系统都无法保证绝对安全。请妥善保护导出文件、保险库密码、备用登录密钥、OAuth 账号以及能够访问扩展的设备。

06

服务提供商与披露

  • Cloudflare 托管并保护官方 Worker 服务和 D1 数据库，同时处理网络及基础设施元数据。
  • GitHub、Google 或 LinuxDo 在您选择相应方式时处理身份验证，并适用其各自的隐私政策。
  • 当您配置扩展连接到用户选择的自托管服务器时，该服务器会接收加密账号桶，并由其运营者控制。

在适用法律要求，或为保护用户、服务及公众免受安全威胁或滥用而具有合理必要性时，我们可能披露相关信息。

07

保存期限

  • 加密账号桶会保留至您删除或账号被删除；
  • OAuth 账号关联及基础账号元数据会在服务账号存在期间保留；
  • 会话及临时 OAuth 记录依据服务配置到期，并定期清理；
  • 登录尝试的 IP 记录仅用于限流，并在保护窗口结束后定期清理；
  • 官方服务的 API 请求限额记录通常保存七天；
  • 扩展本地数据会保留至您清除或卸载扩展，导出文件则保留在您选择的位置。
08

您的选择与删除

您可以删除单个或全部加密账号桶、解除附加 OAuth 提供商关联、退出登录、重置备用登录密钥、删除扩展本地数据或卸载扩展。卸载扩展不会自动删除服务端数据或导出文件。

如需删除官方服务中剩余的账号身份及服务端记录，请通过仓库的私密安全报告渠道联系维护者。请勿在公开 Issue 中发布 Cookie、令牌、备用密钥、数据库导出或其他敏感信息。

09

儿童隐私

Cookie Share Next 并非面向 13 岁以下儿童，我们不会故意收集 13 岁以下儿童的个人信息。

10

Chrome 网上应用店 Limited Use

Cookie Share Next 对从 Google API 获得的信息的使用和转移遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。通过扩展权限取得的数据仅用于提供或改进已公开说明、面向用户的账号状态管理功能。

11

政策变更与联系方式

如发生重大变更，我们会在本页面发布更新并修改日期。隐私问题或请求可通过服务端仓库的私密安全报告渠道提交；普通且不敏感的问题可以使用公开 Issue。
